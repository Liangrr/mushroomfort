# Third-Party Notices

## Bundled typography

The game uses Figtree at regular, medium and bold weights with the approved Noto Sans SC common-character fallback. The browser loading screen embeds a separate small Noto Sans SC subset. Both families are distributed under the SIL Open Font License 1.1; the full notices are retained beside the fonts in `assets/template/fonts/Figtree-OFL.txt` and `assets/template/fonts/NotoSansSC-OFL.txt`. The runtime fallback preserves the canonical 6,547-codepoint repertoire, with its documented upstream U+20BB7 exception in `assets/template/fonts/runtime-cjk.json`.

## Illuminated Grove generated presentation

The owner-approved Illuminated Grove revision replaces the active game artwork and audio with media produced through the built-in generative tools and deterministic runtime processing. These generated replacements do not inherit a catalog publisher's authorship or license merely because they occupy an equivalent gameplay role. Exact available generation facts, input hashes and transformations are recorded in `asset-provenance.json`; a missing backend identifier is not a claim about a particular provider. The v57 typography follows the current Addon font contract described above.
